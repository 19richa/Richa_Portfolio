# Richa — MERN Stack Developer Portfolio

A modern, high-performance interactive portfolio featuring a smooth hardware-accelerated video frame scroll-driven animation, dark glassmorphism design, and responsive layout across all devices.

## 🚀 Live Demo & Features
- **Scroll-Driven Frame Animation**: 190 WebP video frames scrubbed in real-time using an HTML5 `<canvas>` and butter-smooth physics LERP (Linear Interpolation) easing.
- **Modern Glassmorphic Dark UI**: High-contrast, clean typography powered by Plus Jakarta Sans.
- **Fully Responsive**: Optimized for phones (with safe-area insets and mobile drawer), tablets, laptops, and ultra-wide desktops.
- **Comprehensive Portfolio Showcase**:
  - Services & Engineering Expertise (MERN, Autonomous AI & MCP, REST APIs, Database Optimization)
  - About Me & Engineering Approach
  - Technical Skills (Languages, Frameworks, AI & APIs, Databases & Auth)
  - Featured Full-Stack & AI Projects (AI Debugger Assistant, AI Mentor, Mantrix SIH Finalist)
  - Work Experience & Hackathon Achievements (Bharat Economic Forum Intern, SIH Finalist, Gemini Hackathon Runner-Up, etc.)
  - Direct Contact Hub & Downloadable CV (`Richa_CV.pdf`)

## 🛠️ Tech Stack
- **Frontend**: HTML5, CSS3 (Modern Flexbox, CSS Grid, Glassmorphism, CSS `clamp()`), JavaScript (ES6+)
- **Animation**: HTML5 Canvas 2D API, Custom Physics LERP Engine, `requestAnimationFrame`
- **Design System**: Plus Jakarta Sans, Custom SVG Icons

## 💻 Local Development
Clone this repository and run locally:

```bash
git clone https://github.com/19richa/Richa_Portfolio.git
cd Richa_Portfolio
```

Start a local server:
```bash
# Using Python
python -m http.server 3000

# Or using Node / npx
npx serve . -p 3000
```
Open `http://localhost:3000` in your browser.
